# 股票 1 分钟分时复盘

一个本地 Web 复盘工具：输入交易日期，选择多只股票，查询当天 1 分钟分时数据，并叠加到同一张图里对比。

## 启动

```powershell
pip install -r requirements.txt
python app.py
```

打开浏览器访问：

```text
http://127.0.0.1:8000
```

## 功能

- 日期选择
- 股票多选
- 手动添加股票代码，例如 `600519`、`sh600519`、`000001.SZ`
- 同图展示多只股票的 1 分钟曲线
- 支持涨跌幅对比和价格对比
- 图表缩放、还原、保存图片

## 数据说明

行情来自东方财富 1 分钟 K 线接口。该数据源通常只覆盖近期交易日，较早日期、非交易日或停牌股票可能没有返回结果。

默认行情请求不走系统代理；如果你的网络必须通过代理访问外网，可以先设置 `USE_SYSTEM_PROXY=1` 再启动。
